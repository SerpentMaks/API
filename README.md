# Public APIs Catalog

> Каталог публичных API для разработки и экспериментов.

## О проекте

Репозиторий содержит структурированный каталог открытых API по различным категориям: погода, аниме, blockchain, видео, данные и другие сервисы.

Это учебно-справочный репозиторий на основе проекта **public-apis**. Он полезен прежде всего как коллекция источников для прототипирования и тестовых проектов.

## Что внутри

- каталог API по категориям;
- ссылки и краткие сведения о сервисах;
- материалы и правила, связанные с поддержкой каталога;
- конфигурация автоматических проверок исходного проекта.

## Технологии

- Markdown
- Git / GitHub
- GitHub Actions

## Назначение

Используйте каталог для поиска внешнего API перед созданием прототипа или учебного проекта.

> Примечание: репозиторий не следует считать собственной реализацией API-сервиса — это каталог внешних API.

## Статус

📚 Справочный / учебный репозиторий.
