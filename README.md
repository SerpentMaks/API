# Public API Catalog

> Каталог открытых API для поиска сервисов и источников данных для прототипов, учебных работ и экспериментов.

## Что это

Репозиторий представляет собой структурированный каталог публичных API. Это **не собственный API-сервис**, а справочник внешних API, сгруппированных по направлениям.

В каталоге встречаются категории для работы с погодой, аниме, видео, blockchain и другими типами данных.

## Структура

- `scripts/` — вспомогательные скрипты;
- `.github/` — GitHub-конфигурация;
- `CONTRIBUTING.md` — правила работы с каталогом;
- `LICENSE` — лицензия проекта.

## Для чего пригодится

- найти внешний API для учебного проекта;
- быстро подобрать источник данных для прототипа;
- использовать каталог как справочник при изучении REST API.
